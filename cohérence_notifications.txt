RÉSULTAT GLOBAL
───────────────
Structure globale : TRÈS BONNE COHÉRENCE
→ Dans la quasi-totalité des paires, le soir renvoie explicitement à l'action du matin via :
  "As-tu fait X ?", "L'as-tu dit ?", "Avez-vous X ?" + enseignement islamique lié.
→ Aucun cas où le soir parle d'un sujet TOTALEMENT étranger au matin.
→ Problèmes identifiés : 8 écarts, regroupés en 3 catégories ci-dessous.

┌─────────────────────────────────────────────────────────────────────────────┐
│ ÉCART N°1 — LÉGER / Homme / Jour 11                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ Texte matin   : "Si une tension monte aujourd'hui, quitte la pièce          │
│                  5 MINUTES avant de répondre."                              │
│ Texte soir    : "As-tu pu t'arrêter ? 'Le fort est celui qui se maîtrise   │
│                  dans la colère.' — 5 SECONDES de pause évitent des         │
│                  semaines de regret."                                        │
│                                                                             │
│ Problème détecté : Contradiction de durée dans la même paire.               │
│   Le matin prescrit une pause de 5 MINUTES ; le soir la résume à            │
│   5 SECONDES. Ce n'est pas la même technique. Un utilisateur qui             │
│   lit les deux messages le même jour sera perturbé par l'incohérence.      │

│ ÉCART N°7 — MODÉRÉ / Femme / Jour 28                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│ Texte matin   : "Prépare quelque chose de spécial POUR DEMAIN —             │
│                  30 JOURS DE TRAVAIL méritent d'être célébrés."             │
│ Texte soir    : "C'est prévu ? Célébrer les étapes renforce la motivation   │
│                  pour continuer."                                            │
│                                                                             │
│ Problème détecté : Incohérence chronologique.                               │
│   • Ce message est envoyé le JOUR 28.                                        │
│   • "Pour demain" = Jour 29. Or le Jour 29 (dans le plan femme modérée)     │
│     est : "Proposez de renouveler symboliquement votre engagement."         │
│     → Ce n'est pas une célébration.                                          │
│   • La vraie célébration des 30 jours est au JOUR 30.                        │
│   • Le matin du Jour 28 demande de préparer "pour demain" une célébration   │
│     de 30 jours, mais demain (Jour 29) n'est pas la célébration.            │
│   • Le soir est cohérent avec le matin, mais le matin lui-même est          │
│     chronologiquement erroné.                                               │

Écart N°4 — MODÉRÉ HOMME Jour 17 (matin)
  L'action du Jour 17 est quasi-identique au Jour 16 (sortie/promenade).
  Suggestion : remplacer le matin du Jour 17 par une action distincte, ex :
  "Fais-lui une surprise à la maison ce soir : prépare son plat préféré
  ou arrange la pièce avec soin pour créer un espace de détente."

Écart N°5 — GRAVE HOMME Jour 6 (matin)
  Différencier davantage de Jour 1 en insistant sur l'aspect ÉCRIT et
  sur une réflexion plus ciblée (actes spécifiques, non juste l'attitude).
  Ex : "Écris précisément 3 comportements passés qui ont blessé ta femme.
  Pas en général — trois moments datés et concrets."

Écart N°6 — GRAVE FEMME Jour 6 : même correction que N°5.

Écart N°7 — MODÉRÉ FEMME Jour 28 (matin)
  AVANT : "Prépare quelque chose de spécial pour demain — 30 jours de
           travail méritent d'être célébrés."
  APRÈS  : "Prépare quelque chose de spécial pour dans 2 jours — 30 jours
            de travail méritent d'être célébrés ensemble."
  Ou simplement : supprimer "pour demain" et garder "cette semaine".

Écart N°8 — GRAVE H & F Jour 28 (matin)
  AVANT : "Prépare quelque chose de spécial pour demain — 30 jours dans
           une crise méritent d'être reconnus."
  APRÈS  : "Prépare quelque chose de spécial pour dans 2 jours — 30 jours
            dans une crise méritent d'être reconnus."

  • 302 paires (97,4 %) : cohérence complète — le soir renvoie explicitement
    à l'action du matin et l'ancre dans une perspective islamique.
  • 8 écarts identifiés (2,6 %), répartis en :
      - 3 décalages sémantiques (formulation imprécise)

      - 3 incohérences chronologiques ("pour demain" mal positionné)
  • 0 cas où le soir parle d'un sujet TOTALEMENT différent du matin.

Les bonus (bonusMessages.js) sont sans aucun écart — cohérence parfaite.
Les problèmes identifiés sont tous dans notifMessages.js et tous corrigeables
par des ajustements de formulation mineurs.
